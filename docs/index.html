Overview

Il progetto implementa l’algoritmo DAgger (Dataset Aggregation) per l’apprendimento per imitazione in guida autonoma. Inizialmente si colleziona un dataset sotto policy dell’esperto; poi si alternano policy dell’agente e dell’esperto riducendo progressivamente il mixing factor.

  • Due scenari: tracciato su strada (F1 Barcellona-Catalogna) e tracciato a coni (gialli/blu).
  • Per i coni si usa YOLOv8 per detection e bounding box.
  • Training con MSE tra azioni expert e predette; logging TensorBoard.

Metodo (β-mixing)

Ad ogni iterazione, le azioni applicate sono una combinazione lineare tra esperto e agente:

\\[ \\text{policy} = a \\cdot \\beta + \\text{agent} \\cdot (1-\\beta) \\]
Pipeline ad alto livello
  1. Dataset iniziale con policy dell’esperto (umano/controllore).
  2. Training della policy π₁ sul dataset raccolto.
  3. Raccolta dati iterativa in ambiente con mixing β ↓.
  4. Aggregazione dei nuovi esempi etichettati dall’esperto.
  5. Retraining su dataset aggregato fino a convergenza.

Come riprodurre

Installazione

git clone --recurse-submodules https://github.com/MatteoMariani99/psd_DaGGER.git
cd psd_DaGGER
chmod +x install.sh
bash install.sh
# Attiva ambiente
conda activate dagger        # GPU Nvidia
# oppure
conda activate dagger_cpu    # solo CPU

Training / Test

# Test (road)
python3 scripts/test_agent.py

# Test (cones)
python3 scripts/test_agent.py --cones

# Training (road)
python3 scripts/train_agent.py

# Training con ottimizzazione
python3 scripts/train_agent.py --optimize

# Esecuzione DAgger (cones, 42 iterazioni)
python3 scripts/dagger_test.py --cones --num_its=42

Per YOLOv8 sui coni, assicurati che i pesi/dataset siano in posizione come nella repo (vedi README). Vedi anche runs/ per TensorBoard e trajectory/ per le traiettorie.
