Abstract

Il progetto affronta la navigazione autonoma di un’auto da modellismo su due scenari: strada e tracciati delimitati da coni (gialli/blu). Si adotta l’algoritmo DAgger – Dataset Aggregation, che allena una policy deterministica combinando azioni dell’expert e dell’agente, con coefficiente di miscelazione β decrescente.

policy = a · β + agent · (1 − β)

Per i tracciati con coni si impiega YOLOv8 per il rilevamento. Sono disponibili dataset aggregati, modelli allenati e log TensorBoard.

Video

Metodo (DAgger)

Iterazioni: raccolta dati sotto expert → train iniziale (MSE tra azioni expert e predette) → policy mista con β<1 → nuova raccolta → retrain … fino a convergenza.

  • Expert: umano/controllore (P, MPC, …)
  • Per i coni: rilevamento con YOLOv8
  • Output: modelli (dagger_models/), traiettorie (trajectory/), risultati visivi (results/)

Installazione

git clone --recurse-submodules https://github.com/MatteoMariani99/psd_DaGGER.git
cd psd_DaGGER
chmod +x install.sh
bash install.sh

# attiva ambiente
conda activate dagger        # con GPU
# oppure
conda activate dagger_cpu    # solo CPU

Visual Studio Code consigliato con estensione “Python Environment Manager”.

Training

# dataset aggregato strada
python3 scripts/train_agent.py

# tracciato con coni (+ ottimizzazione iperparametri opzionale)
python3 scripts/train_agent.py --cones
python3 scripts/train_agent.py --optimize

Testing

# strada
python3 scripts/test_agent.py

# coni
python3 scripts/test_agent.py --cones

Esecuzione DAgger

# strada (NUM_ITS default 49)
python3 scripts/dagger_test.py

# coni con episodi personalizzati
python3 scripts/dagger_test.py --cones --num_its=42
